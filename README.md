# 旅行小满 · 可扩展游戏原型

先用现有原创美术验证玩法，再逐步接入正式美术和事件内容。项目只维护一套源码：`src/`，构建产物在 `build/`；旧 demo 目录已移除，相关回归测试统一放在 `tests/`。

直接用浏览器打开 [独立体验版](./build/standalone.html)。不需要安装依赖。若浏览器限制本地文件存储，请使用 Node.js 18+ 启动预览：

```powershell
npm run build
npm start
```

打开 <http://127.0.0.1:4174>。修改源码后重新构建；不直接编辑 `build/`。

玩法：点击三叶草田采集金币 → 小摊买食物 → 背包装包 → 等待旅行（20–40 秒，地图支持快进）→ 信箱拆信领取事件金币与明信片 → 收藏并再次出发。

自定义事件：右上角设置 → **事件工坊** → 编辑 JSON 或导入文件 → 保存事件。每趟旅行按条件和权重抽取一条，保存后只影响下一趟；正文作为纯文本显示。可导出 JSON 备份。设置中的“查看沿途小事”可浏览已发生消息。

美术替换入口、素材规格和事件字段见 [原型内容与美术接入说明](./docs/原型内容与美术接入说明.md)。后续准备好素材后，将文件放入 `src/assets/` 并配置 `src/assets.js`；构建会把配置图片内嵌进独立版，缺失资源会使构建失败。

本批次是独立原型，使用原生 JavaScript 和零依赖构建，不代表已完成方案中的 Vite / TypeScript 工程、正式存档协议、Windows / Android 安装包或通知。进度与事件配置分别保存在当前浏览器；使用现有存储键继续保存进度。存储降级行为为：无法保存时仅在当前页面试玩；损坏存档回到初始状态，正式存档容错仍属于 M2。

验证：

```powershell
npm run build
npm test
python -B -m unittest discover -s tests -v
git diff --check
```

本批次自动化覆盖核心循环、事件校验和筛选、冻结旅行结果、重复领奖、离线结算、时间回拨、历史裁剪、美术入口、SVG 和独立版构建。浏览器自动实测受本机端口访问及文件 URL 策略限制，尚未完成；移动端真机和安装包验证留在对应平台阶段。
