# 旅行肥鱼

> 模仿旅行的青蛙让大肥鱼去旅行，回来告诉你它的经历并且给你带回礼物

一个**非商业、开源、自研**的放置旅行小游戏。玩法致敬《旅行青蛙》，但与原版没有任何关系：
代码、美术、文案均为本项目原创，**不包含任何原版游戏的素材或代码**。

## 现状

仓库目前处于「原型可跑」阶段，游戏本体在 `demo/` 目录里：

- 纯前端网页版，零运行时依赖（原生 ES Module + SVG 素材）
- 无后端，存档落在浏览器本地；可打包成单文件 HTML 直接双击打开

## 快速开始

```bash
cd demo

# 1) 构建 + 起本地服务（默认 http://127.0.0.1:4173）
node build.mjs && node server.mjs

# 2) 或者直接生成单文件版本，双击打开
node build.mjs            # 产物：demo/dist/standalone.html
```

## 跑测试

```bash
cd demo
node --test tests/
```

## 目录结构

```
demo/
├── dist/            构建产物（含 standalone.html 单文件版）
├── tests/           node:test 单元测试
├── build.mjs        把 index.html + js + css + svg 内联成单文件
├── server.mjs       极简静态服务器
└── 界面验证.md      浏览器端手工验收记录
```

## 玩法（当前版本）

- **钱草**是货币，收割攒钱；**食物**（饭 / 三明治 / 蛋糕）和**道具**（地图 / 水杯）影响出行
- 出门 → 旅行中 → 归来 → 领取明信片，四段状态机
- 明信片按主题（山丘 / 小镇 / 湖）随机掉落，共 9 张
