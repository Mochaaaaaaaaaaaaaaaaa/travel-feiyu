# 旅行小满 · 前端 Demo

一个零依赖的界面与流程原型。使用原创 SVG 绘制家园、角色、物品和旅行风景，无后端、无账号、无外部图片或字体请求。

## 启动

直接打开 [独立体验版](./dist/standalone.html) 即可体验，无需安装依赖或启动服务。独立版由 `node demo/build.mjs` 从源文件生成；修改源码后需重新生成。

如需开发预览，需要 Node.js 18 或更高版本，在项目根目录运行：

```powershell
node demo/server.mjs
```

浏览器打开 <http://127.0.0.1:4173>。也可以进入 `demo` 后运行 `npm start`。

## 建议体验顺序

1. 点击家园左下角的钱草田，获得 30 钱草。
2. 打开「林间小铺」购买食物，余额和背包数量会实时变化。
3. 打开「收拾行囊」，选择食物与小物，确认准备。
4. 小满准备 2 秒后自行出发。等待 20～40 秒，或点击页面底部「快进旅行」。
5. 小满归来后点击信箱或「拆开来信」，将明信片珍藏进旅行手记。
6. 查看图鉴、切换山野/小镇/湖畔分类，再准备下一趟。

初始赠送 80 钱草、2 份饭团和 1 张永久地图。地图增加山野倾向，小杯增加小镇倾向；食物决定模拟旅行时长。钱草每 30 秒成熟一轮，不累计多轮离线收益。关闭或刷新页面后，旅行按时间继续推进，奖励只能领取一次。

进度仅存储在当前浏览器的 localStorage，浏览器不允许存储时降级为当前页面内存。底部「重新体验」在确认后恢复初始状态。音效默认关闭，可在右上角切换。

## 验证

在项目根目录执行：

```powershell
node --test demo/tests/game.test.mjs demo/tests/assets.test.mjs
python -B -m unittest discover -s tests -v
git diff --check
```

自动化测试覆盖资源与购买、行李选择、旅行状态、目的地倾向、归来领取、离线推进与损坏存档恢复。界面验证记录见 [界面验证.md](./界面验证.md)。
