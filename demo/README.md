# 旅行小满 · 前端 Demo

一个零依赖的界面与流程原型。首屏是一整幅开放式小屋与庭院，所有主要入口都藏在画面物品里。使用原创 SVG 绘制家园、角色、物品和旅行风景，无后端、无账号、无外部图片或字体请求。

## 启动

直接打开 [独立体验版](./dist/standalone.html) 即可体验，无需安装依赖或启动服务。独立版由 `node demo/build.mjs` 从源文件生成；修改源码后需重新生成。

如需开发预览，需要 Node.js 18 或更高版本，在项目根目录运行：

```powershell
node demo/server.mjs
```

浏览器打开 <http://127.0.0.1:4173>。也可以进入 `demo` 后运行 `npm start`。

## 建议体验顺序

1. 点击家园左下角的钱草田，获得 30 钱草。
2. 点击院边的条纹棚小摊，购买食物，余额和背包数量会实时变化。
3. 点击屋内左边挂着的背包，选择食物与小物，确认准备。
4. 小满准备 2 秒后自行出发，角色与背包暂时离开画面。等待 20～40 秒，或点击桌上地图查看倒计时并快进。
5. 小满归来后，信箱露出新来信。点击信箱，将明信片珍藏进旅行手记。
6. 点击墙上的明信片板查看图鉴、切换分类；再点背包准备下一趟。

不再设置侧边导航、介绍卡片或底部工具栏。左上角只显示钱草，右上角是设置。物品名称在悬停或键盘聚焦时出现；设置中的「显示名称」可一次展示全部入口。桌面横向排列屋内与庭院，手机竖屏将庭院移到屋内下方，画面无需拖动或滚动。物品点击区域最小为 44×44 CSS 像素。

初始赠送 80 钱草、2 份饭团和 1 张永久地图。地图增加山野倾向，小杯增加小镇倾向；食物决定模拟旅行时长。钱草每 30 秒成熟一轮，不累计多轮离线收益。关闭或刷新页面后，旅行按时间继续推进，奖励只能领取一次。

进度仅存储在当前浏览器的 localStorage，浏览器不允许存储时降级为当前页面内存。右上角设置里可以切换音效、显示物品名称，或在确认后重新体验。Demo 快进可从旅行中的地图弹窗或设置进入。

## 验证

在项目根目录执行：

```powershell
node --test demo/tests/game.test.mjs demo/tests/assets.test.mjs demo/tests/scene.test.mjs
python -B -m unittest discover -s tests -v
git diff --check
```

自动化测试覆盖资源与购买、行李选择、旅行状态、目的地倾向、归来领取、离线推进与损坏存档恢复。界面验证记录见 [界面验证.md](./界面验证.md)。

Python 测试还会严格解析实际生成的 SVG，检查分组闭合、室外物品层级及绘图与点击区域坐标的一致性，防止浏览器自动修复错误标签后出现画面错位。

本 Demo 用于评估视觉和交互，价格、时长、概率均为体验配置。尚未加入完整养成内容、服务器校时、多标签页并发写入协调和正式云存档。
