## 体验范围

- 手机端为桌面浏览器的视口模拟，尚未进行实体设备或多浏览器兼容性测试。
- 单文件版通过本地 HTTP 完成浏览器验证；直接以文件打开时，存档受浏览器设置影响，不可用时退回内存模式。
- 首次提示背包入口，悬停或键盘聚焦显示物品名称；触屏用户可从设置统一显示名称。
- 9 张明信片拥有独立标题与短故事，暂复用 3 套主题插画。时长、价格和概率仍为 Demo 配置。
- 多标签页并发写入、服务器校时和云存档不在本轮范围。

## 物品错位修复回归

用户反馈独立版中钱草田移到屋内，信箱压到椅子前，点击区域仍在原地。检查发现桌上物品的 SVG 分组重复打开但未对应闭合，浏览器自动修复标签后把后续庭院物品嵌入了小屋变换中。

- 先增加严格 SVG XML 解析测试，在原版的 6 个视口下均复现结构错误，再修正分组并重新生成独立版。
- 为小屋、小摊、信箱、草田和桌上物品增加明确分组标识，断言室外物品是 SVG 根下的独立分组，桌面变换不包含角色。
- 比较生成的绘图平移量与点击区域布局，覆盖 1920×991、1920×1080、1440×900、1050×930、390×844、320×740。
- 浏览器实测 1920×991 和 390×844，读取七个绘图物品的实际屏幕边界，中心点均落在对应点击区域内。按画面中的钱草田坐标点击，余额由 85 增至 115。
- 背包可正常打开行李弹窗；最终预览没有浏览器错误日志。
- 浏览器工具只允许 HTTP/HTTPS，无法直接打开 file 协议；本次通过本机 HTTP 加载同一份 standalone.html 验证。

修复截图：本地 `demo/.preview/alignment-fixed-desktop.jpg`、`demo/.preview/alignment-fixed-mobile.jpg`。全部 33 项测试通过。
