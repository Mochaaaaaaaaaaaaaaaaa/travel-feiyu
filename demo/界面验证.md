# Demo 场景改版验证

日期：2026-11-12。验证对象：全画幅小屋、场景物品入口和独立体验版，无后端。

## 自动化验证

- 前端逻辑、静态资源与场景布局测试：26 项通过。
- 产品文档测试：3 项通过。
- JavaScript 语法检查、独立版可重复构建和 Git 空白检查通过。
- 布局测试覆盖 1440×900、1050×930、1920×1080、844×390、390×844、320×740、768×1024，所有物品的世界坐标均在可见区域内且相互不重叠。
- 回归检查确保首页不再包含侧边导航、标题面板、外围介绍卡片或底部工具栏；七个场景物品均有对应操作入口。

## 浏览器实测

| 检查 | 结果 |
| --- | --- |
| 桌面首屏 | 1440×900 视口实测，开放式小屋、庭院和场景物品完整显示；只在角落保留余额与设置 |
| 背包入口 | 点击墙边背包打开行李弹窗；确认后进入准备、自动出发，角色和背包离开场景 |
| 地图入口 | 旅行中点击桌上地图查看倒计时与快进入口；刷新后仍可正确查看进行中的旅行 |
| 快进归来 | 从地图快进后显示来信；关闭弹窗返回场景，角色、背包和信箱里的信件均可见 |
| 信箱领取 | 点击信箱拆信并珍藏，重复卡数量从 1 增至 2；旅行次数正确增为 2 |
| 明信片板 | 点击墙上的照片板打开旅行手记，显示 1/9 种回忆与已旅行 2 次 |
| 小摊入口 | 点击庭院小摊打开商店；购买饭团后余额由 105 减至 85，库存由 1 增至 2，反馈提示在弹窗内可见 |
| 设置 | 音效可以切换；显示物品名称后关闭设置，返回场景看到所有入口名称 |
| 手机布局 | 390×844 视口实测，小屋在上、庭院在下，不需拖动或滚动 |
| 窄屏点击范围 | 320×740 视口读取实际 DOM 边界，所有可见物品点击区域均不小于 44×44 CSS 像素，未越出屏幕 |
| 弹窗与键盘 | 320px 下行李弹窗没有横向溢出；Escape 可关闭弹窗并将焦点还给原来的背包入口 |
| 存档兼容 | 原版已有钱草、库存与图鉴继续保留；改版未清除存档 |
| 错误日志 | 最终独立版预览的浏览器错误日志为空 |

本次桌面和手机截图保存在本地 `demo/.preview/cottage-desktop.jpg` 与 `demo/.preview/cottage-mobile.jpg`，不作为运行依赖提交。

## 体验范围

- 手机端为桌面浏览器的视口模拟，尚未进行实体设备或多浏览器兼容性测试。
- 单文件版通过本地 HTTP 完成浏览器验证；直接以文件打开时，存档受浏览器设置影响，不可用时退回内存模式。
- 首次提示背包入口，悬停或键盘聚焦显示物品名称；触屏用户可从设置统一显示名称。
- 9 张明信片拥有独立标题与短故事，暂复用 3 套主题插画。时长、价格和概率仍为 Demo 配置。
- 多标签页并发写入、服务器校时和云存档不在本轮范围。
