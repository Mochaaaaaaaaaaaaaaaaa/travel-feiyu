# 旅行养成小游戏 · MVP 产品设计

版本：v0.1｜日期：2026-11-12｜状态：首版范围草案

## 1. 产品方向

做一款轻松、治愈的旅行养成小游戏。玩家为一只小动物准备行李，看它在家生活、独自旅行，再收到它从远方带回的明信片。

面向喜欢可爱角色、轻度收集和碎片化体验的玩家。每次打开只需操作几分钟，离开后旅行继续推进，没有忘记照顾就受罚的压力。

参考《旅行青蛙》和[《旅行奶蛙》](https://www.bilibili.com/toy/TravelMilkyFrog/index.html)的旅行与收集循环，角色、美术、文案和世界设定采用自己的设计。首版暂定为浏览器端单人游戏，优先适配手机竖屏，兼顾桌面浏览器。

## 2. 首版要验证什么

- **牵挂角色**：玩家能感受到它在自己生活，愿意回来看看。
- **期待结果**：玩家想知道这次去了哪里、会带回什么故事。
- **愿意再玩**：收到第一张明信片后，会主动准备第二次旅行。

首版优先打磨角色表现、旅行归来的反馈和明信片内容，系统数量保持克制。

## 3. 核心体验循环

**收取钱草 → 购买补给 → 准备行李 → 角色自行出发 → 等待归来 → 领取明信片 → 查看图鉴 → 再次准备。**

首次进入时赠送基础补给，引导玩家完成收取、装包和第一次旅行。第一趟约 1 分钟，保证尽快看到完整回报；后续旅行暂定 10～30 分钟，具体节奏通过试玩调整。

角色状态为：**在家 → 准备好 → 旅行中 → 归来待领取 → 在家**。玩家确认行李后，角色短暂准备再自动出发；旅行途中无需操作，奖励领取后才能安排下一趟。

## 4. 主要功能

| 功能 | MVP 范围 | 体验重点 |
| --- | --- | --- |
| 家园与角色 | 1 个固定家园场景、1 只角色；吃饭、看书、睡觉等 3～4 个简单动作 | 角色在家时有生活感；外出时显示空屋、旅行状态和大致归来时间 |
| 钱草采集 | 1 种货币、1 块定时成熟的草田，点击收取 | 提供轻量互动；离线最多保留一轮成熟收成，不无限累积 |
| 商店与背包 | 3 种食物、2 种永久道具；显示价格、数量和作用 | 食物出发时消耗 1 份，道具重复使用；初始赠送能完成首趟的补给 |
| 行李准备 | 1 个食物槽、1 个可选道具槽；有食物即可准备出发 | 食物影响旅程时长，道具影响目的地倾向，界面用一句话说明作用 |
| 放置旅行 | 自动出发、按时间归来、离线继续推进 | 不需一直开着页面；关闭后再打开也能正确看到旅行结果 |
| 旅行回报 | 3 个目的地、约 9～12 张固定明信片；每次带回 1 张及一句短故事 | 目的地保留随机性，道具只改变倾向；首次保证获得新卡 |
| 明信片图鉴 | 已收集列表、未收集剪影、收集进度、明信片大图 | 重复明信片记录获得次数；首版不做稀有度和兑换 |
| 引导与存档 | 简短首次引导、本地自动保存、基础音效开关 | 保存货币、物品、旅行状态和图鉴；提示存档仅在当前设备与浏览器有效 |

初始平衡原则：免费钱草持续再生，玩家用完补给后仍能通过等待收菜继续出发；首次奖励只发放一次，避免重复刷新刷取。

## 5. 页面与视觉方向

采用 **1 个家园主画面 + 3 个弹窗**，减少页面切换和制作成本。

- **家园主画面**：角色、小屋、草田、货币、旅行状态；归来时信箱有明显提示，点击展示本次明信片。
- **行李弹窗**：选择食物和道具、查看倾向与预计时长、确认准备；外出时查看旅行状态。
- **商店弹窗**：展示 5 种物品，支持购买与查看已有数量。
- **图鉴弹窗**：浏览明信片、查看故事和收集进度。

整体采用温暖柔和的配色与统一插画风格。美术优先级是角色辨识度、家园氛围、明信片画面；先保证少量内容有吸引力。

## 6. 首版边界

本版只包含单人旅行、资源准备和明信片收集，不加入以下功能：

- 好友、排行榜、社交分享、每日任务、签到、付费和广告。
- 装修、烹饪、设施升级、自动收菜、多角色和大地图探索。
- 明信片稀有度、抽卡保底、重复卡兑换和复杂装备属性。
- 实时 AI 生成图片或故事、账号系统、跨设备云存档。

本地存档适合首轮小范围试玩；清除浏览器数据会丢失进度。是否需要账号与云存档，在公开测试前另行评估。

## 7. 验收与试玩观察

交付试玩前，需通过以下验证：

1. 新玩家不依赖口头说明，可以完成第一趟旅行并查看明信片。
2. 收菜、购买、装包、出发、归来和再出发能连续完成，货币与物品数量正确。
3. 旅行中刷新或关闭页面，再打开后时间与状态正确；等待超过归来时间后可以直接领取。
4. 同一趟旅行奖励只能领取一次，刷新不会重复发放；首次补给不会重复赠送。
5. 保存并重新打开后，货币、物品和图鉴保持一致；重复卡正确累计次数。
6. 手机竖屏和桌面浏览器均可操作，主要按钮不被遮挡，文字清晰可读。

首轮邀请少量玩家试玩，记录：是否完成首趟、是否主动准备第二趟、是否隔一段时间回来，以及最期待和最困惑的地方。先用人工观察与反馈记录，不为首版增加复杂的数据平台；暂不承诺未经验证的留存目标。

## 8. 后续方向

先完成旅行与存档闭环，再加入全部首版美术和明信片，最后进行试玩与节奏调整。角色名称、具体目的地主题、价格和概率，在实现前作为内容配置确定。

若玩家愿意持续出发，优先扩充目的地、明信片故事和角色日常互动；再根据反馈考虑少量家园装饰与云存档。
